# yarduuid

Yard timestamps and uuid durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/yarduuid/

## Install / run

```bash
git clone https://github.com/theworker02/yarduuid.git
cd yarduuid
node src/cli.js
node --test
```
